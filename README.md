# 💰 Refund

Projeto para operação de reembolso desenvolvido com JavaScript.

## 📖 Sobre

Aplicação web que simula um fluxo de solicitação de reembolso de despesas, com manipulação do DOM e lógica de cadastro/listagem em JavaScript.

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript
